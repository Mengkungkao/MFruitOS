# 2026-10-05 — AI Chatbot 1.0.1: installs from its own release only

## Context

The user asked for AI Chatbot to install from the Fruit Store using only
their ai-chatbot repository, with nothing downloaded from PiSugar's
whisplay-ai-chatbot. Before this, the 1.0.0 release build fetched the font
and emoji set from `storage.whisplay.ai`, and the device's `install.sh`
downloaded Node.js from nodejs.org when the board had no Node.js 20 (the Pi
Zero did, at 12:31 today). The stock emoji also overwrote the cat faces, so a
face emoji inside a reply's text showed the yellow emoji.

## Revisions

- ai-chatbot `57be5b9` (tag `v1.0.1`): font (`a9c048e5…`) and emoji zip
  (`d82effae…`) kept in `python/` with their licences (`python/ASSETS.md`);
  `tools/build-release.sh` checks them, draws the cat faces over the emoji
  and bundles Node.js 20.19.5 (`d4622678…`, linux-arm64) in `runtime/`;
  `install.sh` downloads nothing; `test.sh` refuses a package without the
  font, emoji or cat faces.
- Release asset `whisplay-ai-chatbot-1.0.1-linux-arm64.tar.gz`, 92 MB,
  SHA-256 `c8ead71c2e54e3b1b7b302d4dc90ecb73051e476a61ac2486450db57cb05d175`,
  built by the GitHub Actions Release workflow (success).
- MFruit OS `1b2dafd`: catalogue pin 1.0.0 → 1.0.1.
