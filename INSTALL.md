# Installing mFruit OS

The installation guide is [docs/platform/INSTALLATION.md](docs/platform/INSTALLATION.md):
requirements, board preparation, check, install, verify, update, rollback and
uninstall. Problems: [docs/quality/TROUBLESHOOTING.md](docs/quality/TROUBLESHOOTING.md).

Quick start on a prepared device:

```bash
git clone https://github.com/Mengkungkao/MFruitOS.git
cd MFruitOS
bash scripts/setup-device.sh --check
bash scripts/install.sh
```
